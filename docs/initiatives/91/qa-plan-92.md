## Backend — 結合テスト（実 DB、I-XX）

このタスクには新しい HTTP エンドポイントが無い。結合テストは **実 PostgreSQL に対するドメインサービス／リポジトリのテスト**として行う。
`RaidDomainService` の 3 メソッド（3凸報告・報告取り消し・参加取り消し）が対象。

### 3凸報告（自動参加）

| ID | シナリオ | 期待 | 優先度 |
|----|---------|------|-------|
| I-01 | 未参加のユーザーが 3凸報告する | 報告が保存され、参加者にスコア 0・`username` = 報告者名で登録される。結果は「自動登録した」 | 🔴 |
| I-02 | 手動で参加登録済み（スコア入力済み・別名）のユーザーが 3凸報告する | 参加者の `username`・スコア・参加日時は上書きされない。結果は「自動登録していない」 | 🔴 |
| I-03 | 同じ難易度を再報告する | 報告は 1 行のまま（時刻更新）、結果は「報告済みだった」 | 🟡 |
| I-04 | 別の難易度を続けて報告する | 報告 2 行、参加者は 1 行のまま | 🟡 |
| I-05 | 終了済みレイドに報告する | 失敗（終了済みエラー）。報告も参加者も作られない | 🔴 |
| I-06 | 存在しないレイドに報告する | 失敗（レイドなしエラー）。何も作られない | 🟡 |

### 3凸報告の取り消し（自動削除）

| ID | シナリオ | 期待 | 優先度 |
|----|---------|------|-------|
| I-07 | 唯一の報告を取り消す（報告 0 件になる） | 報告と参加者の両方が削除される。結果は「参加者から外れた」 | 🔴 |
| I-08 | 2 難易度報告済みで 1 つだけ取り消す | 残りの報告と参加者は残る | 🔴 |
| I-09 | 手動登録でスコア入力済みの人が、報告を全部取り消す | 参加者（入力済みスコアごと）が削除される（blueprint 明記） | 🔴 |
| I-10 | 報告していない難易度だけを指定して取り消す（報告なしの手動登録者） | 何も消えない。参加者は残る | 🟡 |
| I-11 | 参加者の行が無い既存の報告（移行なしのデータ）を取り消す | エラーにならず報告が消える | 🟡 |
| I-12 | 終了済みレイドで取り消す | 失敗（終了済みエラー）。報告も参加者も残る | 🟡 |
| I-13 | 難易度を 1 つも選ばずに取り消す | 失敗（難易度未選択エラー） | 🟢 |

### 参加取り消し（新規ドメインメソッド）

| ID | シナリオ | 期待 | 優先度 |
|----|---------|------|-------|
| I-14 | 参加者かつ全難易度報告済みの人の参加を取り消す | 参加者と全報告がまとめて削除される。結果に削除件数が入る | 🔴 |
| I-15 | 同じレイドの他ユーザー・他レイドの同じユーザー | 対象以外の参加者と報告は残る | 🔴 |
| I-16 | 報告だけあり参加者の行が無い人の参加を取り消す | 報告は削除される | 🟡 |
| I-17 | 参加者でも報告者でもない人の参加を取り消す（二重送信など） | 成功し、件数は 0（冪等） | 🟡 |
| I-18 | 存在しないレイドの参加を取り消す | 失敗（レイドなしエラー） | 🟡 |
| I-19 | 終了済みレイドの参加を取り消す | 削除できる（終了済みの可否は web 側の権限判定で決める方針） | 🟡 |

### 整合性（トランザクション・同時実行）

blueprint の「各処理はトランザクション内で行い、参加者と報告の整合性を保つ」に対応。**テストのトランザクションに乗らない形**（実コミット）で確かめる必要がある。

| ID | シナリオ | 期待 | 優先度 |
|----|---------|------|-------|
| I-20 | 3凸報告の途中（参加者の登録）で DB 例外が起きる | 全体がロールバックし、報告の行も残らない | 🔴 |
| I-21 | 「最後の報告の取り消し」と「同じ人の別難易度の報告」が同時に走る | 後から来た処理は前の処理のコミットを待つ。結果として「報告があるのに参加者がいない」状態にならない | 🔴 |
| I-22 | トランザクションの外から 3 メソッドを呼ぶ（設定漏れ・プロキシを通らない呼び出し） | 書き込み前に止まり、行が増減しない | 🟡 |
| I-23 | 「報告」と「レイド終了」が同時に走る | 終了が先にコミットされたら報告は終了済みエラーになり、報告も参加者も残らない | 🟢 |
| I-24 | 参加取り消しの途中で DB 例外が起きる | 報告だけ消えて参加者が残る、のような中途半端な状態にならない | 🟢 |
